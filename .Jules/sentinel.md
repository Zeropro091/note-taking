## 2024-05-20 - Path Traversal bypass via Backslash normalization
**Vulnerability:** A path traversal vulnerability existed in `validateNoteId` where attackers could bypass the `.startsWith('..')` protection on POSIX systems by using Windows-style backslashes (e.g., `somefolder\..\..\etc\passwd`). Node's `path.resolve` on non-Windows platforms doesn't treat `\` as a separator, resolving the entire string as a single filename. However, when later passed to `fs` methods or URL resolution, this could bypass folder restrictions and lead to unintended file access.
**Learning:** Checking for traversal sequences using `startsWith('..')` after `path.resolve` on Linux/macOS does not account for `\` if it's treated as part of the filename, but other APIs might later treat `\` as a separator.
**Prevention:** Always normalize `\` to `/` (e.g., `id.replace(/\\/g, '/')`) BEFORE calling `path.resolve` and `path.relative` when validating paths to prevent environment-specific traversal bypasses.
