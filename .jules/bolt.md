## 2024-05-18 - Optimize GraphView derived state array performance bottleneck
**Learning:** In highly interactive React components (like `react-force-graph-2d` receiving continuous hover events), doing un-memoized derived state calculations that include nested array iteration (`O(N*E)`) severely drops frame rates and bogs down performance. Here, `graph.edges.filter` was iterating over all edges, and calling `graph.nodes.find()` twice inside the loop for every render, leading to significant slow downs.
**Action:** When filtering array-based relationships (like graph edges referencing nodes), precompute a `Set` or `Map` of valid entity IDs before the loop. This converts `O(N*E)` inner-loop traversals into `O(N+E)` operations with `O(1)` lookups. Additionally, always wrap expensive derived objects (like node and link object mapping) in `useMemo` so they aren't redundantly recreated during frequent state updates like hover states.
