## 2026-06-06 - Wrap currentData in useMemo\n**Learning:** In React components with heavily derived state like graph visualization data, recreating the data on every render (like `const currentData = { nodes: ..., links: ... }`) triggers lint warnings (`react-hooks/exhaustive-deps`) when passed to `useEffect` or `useCallback`, and hurts performance. It needs to be wrapped in `useMemo`.\n**Action:** Always wrap expensive or derived state meant for downstream hooks in `useMemo`.
