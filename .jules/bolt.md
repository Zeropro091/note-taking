## 2024-06-19 - GraphView Derived State Optimization
**Learning:** For React performance with data-heavy components (e.g., `react-force-graph-2d`), always wrap expensive derived states like node and link objects in `useMemo` to prevent exhaustive-deps warnings and redundant recalculations on frequent events like hover or regular re-renders. Furthermore, when performing lookups within array `.filter()` or `.map()` methods (e.g., finding nodes associated with graph edges), optimize time complexity by precomputing a `Set` or `Map` of valid IDs before the loop. This reduces O(N*E) operations to O(N+E).
**Action:** When reviewing or writing code that computes derived state from large data collections (like graph nodes and edges), proactively use `useMemo` and employ HashSets/HashMaps (`Set` / `Map`) for cross-referencing collections to avoid O(N²) or O(N*M) nested loop bottlenecks inside render functions.
