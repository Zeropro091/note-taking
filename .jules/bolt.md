## 2024-05-29 - O(N*E) Array Lookup Bottleneck in React Data Visualizations
**Learning:** Found a severe performance bottleneck where graph edges were being filtered using `Array.prototype.find()` on the nodes array for each edge (`O(N*E)` complexity). Because `currentData` was re-evaluated on every React render (such as hovering over nodes), this caused UI stuttering on data-heavy visualizations. Additionally, `useMemo` was completely missing for expensive data transformations like this and full array flat-maps.
**Action:** Always wrap heavy data transformations (especially related to visual graph state) with `useMemo`. When joining or verifying associations between arrays (e.g. nodes and edges), always precompute a `Map` or `Set` of IDs (`O(N)`) before looping through the second array (`O(E)`), reducing total lookup time to `O(N+E)`.
