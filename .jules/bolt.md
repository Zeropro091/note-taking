## 2023-11-20 - Graph Rendering O(N*E) Bottleneck
**Learning:** In `GraphView.tsx`, calculating graph data dependencies in the render loop involved calling `.find()` on an array of nodes (size N) inside a `.filter()` loop over edges (size E) to determine if edge source/targets had a matching tag. This resulted in O(N*E) complexity, which is highly inefficient and hurts React performance during re-renders, especially when hover/interaction state changes happen frequently.
**Action:** When performing lookups within array `.filter()` or `.map()` methods (e.g., finding nodes associated with graph edges), optimize time complexity by precomputing a `Map` of valid IDs before the loop. Also, wrap expensive derived states like node and link objects in `useMemo` to prevent redundant recalculations. This reduces O(N*E) operations to O(N+E).
