## 2024-11-23 - Accessibility for Accordion Groups
**Learning:** Accordion-style UI elements constructed with `framer-motion` for transitions (e.g. `AnimatePresence`) can easily lose critical screen reader context. Specifically, toggle buttons need explicit relationship mappings (`aria-controls`, `id`, `aria-expanded`) to their collapsible content blocks to provide an accessible experience, and they need explicit visible focus states (e.g. via Tailwind `focus-visible`) for keyboard navigation.
**Action:** When implementing collapsible UI groups or sidebar elements using React components and animations, ensure `aria-expanded` and `aria-controls` on the toggle trigger matches the `id` of the collapsible target container. Also ensure `focus-visible` classes are applied so keyboard users can navigate these elements easily.
