## 2024-05-23 - GraphView Toolbar and Toggle Button Accessibility
**Learning:** When using custom icon buttons inside interactive canvases or specialized toolbars (like the ForceGraph view), screen readers fail to read the visual `title` prop. Also, toggle-style actions (like Pause/Resume, Isolate, Fullscreen) need `aria-pressed` to indicate their current state correctly rather than just relying on changing icons or titles. Additionally, dynamically generated tag filter buttons must explicitly indicate whether they are the currently active filter using `aria-pressed` and include clear `focus-visible` styles for keyboard navigation in crowded overlays.
**Action:** Always map the `title` text to an `aria-label` for icon-only action buttons. Use `aria-pressed={booleanState}` on buttons that act as toggles. Ensure dynamic lists of filter buttons have visible focus states (`focus-visible:ring-2`) and use `aria-pressed` to communicate the active filter to assistive technologies.
