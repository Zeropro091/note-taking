## 2026-06-09 - Path Traversal Vulnerability Mitigation (POSIX Backslash Bypass)
**Vulnerability:** The initial path traversal fix in `validateNoteId` used `path.resolve` and `path.relative` on user input, which failed to protect against attackers using backslashes to bypass logic on POSIX systems (e.g., `folder\..\..\etc\passwd`). Path traversal was still possible.
**Learning:** `path.resolve` and `path.relative` handle slashes differently depending on the operating system environment they run in. On POSIX systems, a string like `..\\..\\etc\\passwd` is treated as a single literal filename component, not directory traversal characters. If it is passed into further operations that re-evaluate it (or if it's evaluated elsewhere like `fs` modules on different systems), it might open the door to bypasses.
**Prevention:** Normalize backslashes to forward slashes BEFORE resolving the path relative to the base directory, preventing POSIX traversal bypasses. As a defense-in-depth measure, explicitly reject any IDs containing `..` to prevent traversal attempts.
