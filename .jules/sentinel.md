## 2024-06-23 - Path Traversal bypass via Windows backslashes on Linux
**Vulnerability:** A path traversal vulnerability existed in `validateNoteId` where a Windows-style path traversal like `folder/..\\..\\etc\\passwd` would return `true` on Linux because `path.resolve` and `path.relative` treat `\\` as part of the filename. However, a subsequent `sanitizeNoteId` function would blindly normalize `\\` to `/` for cross-platform compatibility, effectively realizing the path traversal into an actionable path `folder/../../etc/passwd` that allowed reading files outside the notes directory.
**Learning:** `path.resolve` and `path.relative` behavior varies by the underlying OS environment. Path validation using these modules must happen *after* any custom slash normalization if a subsequent operation normalizes the slashes, because validation can be bypassed.
**Prevention:** Normalize backslashes (`\`) to forward slashes (`/`) *before* applying path resolution or validation, and consider an explicit rejection of `..` string sequences as a defense-in-depth measure.
