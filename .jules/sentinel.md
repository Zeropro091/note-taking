## 2024-07-05 - Path Traversal Bypass via OS-Specific Directory Separators
**Vulnerability:** A path traversal check in `validateNoteId` was vulnerable to a bypass. Windows-style paths like `..\..\Windows\System32` or nested path traversals like `folder/../../note` could potentially bypass naive string matching or subsequent sanitization due to incomplete initial validation, relying on path resolution quirks on different operating systems.
**Learning:** Checking for traversal payloads without standardizing directory separators leaves vulnerabilities open if the underlying framework handles non-standard separators (e.g., `path.resolve` correctly handling Windows backslashes in some contexts or normalizing them later). Defense-in-depth requires checking normalized inputs.
**Prevention:** Normalize all directory separators (e.g., replace `\` with `/`) BEFORE applying validation rules or using functions like `path.resolve`. Furthermore, use robust regex bounded by path separators `/(^|\/)\.\.(?=\/|$)/` to reject traversal characters rather than simple string checks that could break valid file names with adjacent dots.
