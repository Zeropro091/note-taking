## 2024-07-03 - Path Traversal Bypass via Unnormalized Backslashes
**Vulnerability:** Path traversal attacks can bypass directory validation if backslashes are not normalized to forward slashes before doing path resolution, and by not explicitly blocking the sequence `..`. An attacker could exploit this using sequences like `foo/..\..\..\etc\passwd`.
**Learning:** Checking for traversal by merely validating against a root directory after built-in path resolution might fail when path traversal is obfuscated using combinations of forward and backward slashes, as Node's path resolve handles path normalization on POSIX somewhat differently for backslashes. Relying solely on `path.resolve` and `path.relative` is insufficient.
**Prevention:** Always normalize slashes (`replace(/\\/g, '/')`) BEFORE path resolution, and explicitly forbid path traversal attempts by blocking strings containing consecutive dots acting as parent directory indicators using boundaries (e.g. `/(^|\/)\.\.(?=\/|$)/`) rather than broad checks which might flag legitimate filenames like `my..note`.
