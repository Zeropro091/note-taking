## 2025-05-29 - Path Traversal Bypass via Normalization Mismatch
**Vulnerability:** The `validateNoteId` function was vulnerable to path traversal bypasses because it checked for `..` traversals *before* normalizing backslashes (`\`) to forward slashes (`/`), or relied implicitly on node's `path.resolve`. Although `path.relative` provided some protection, backslash paths on Unix-like platforms could bypass rudimentary checks or cause unexpected resolution behaviors.
**Learning:** Normalization of input (e.g. replacing `\` with `/`) MUST happen *before* any validation checks or path resolutions. Furthermore, explicit blacklisting of traversal patterns (like `..`) provides defense-in-depth even when using high-level methods like `path.resolve` and `path.relative`, protecting against unexpected edge cases across different OS platforms.
**Prevention:** Always normalize all slashes to a single separator (`/`) immediately upon receiving input, and explicitly reject known traversal characters (`..`) as a strict defense-in-depth measure before proceeding to built-in path resolution functions.
