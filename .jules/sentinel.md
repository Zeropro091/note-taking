## 2025-07-02 - Path Traversal Bypass via Backslashes on POSIX Systems
**Vulnerability:** The `validateNoteId` function was vulnerable to a path traversal bypass on POSIX systems when user input contained backslashes (e.g. `some_folder/..\..\..\etc\passwd`). `path.resolve` treats backslashes as valid filename characters on POSIX, meaning the string passes the traversal checks (`!relative.startsWith('..')`), but a later `id.replace(/\\/g, '/')` converted those backslashes into standard forward-slash directory separators, effectively recreating the path traversal vulnerability.
**Learning:** Checking for path traversal via `path.resolve()` and `path.relative()` can be bypassed on POSIX systems if input containing backslashes is subsequently normalized. The normalization logic transforms safe-looking strings into dangerous ones.
**Prevention:** Normalize backslashes (`replace(/\\/g, '/')`) BEFORE passing the user input to `path.resolve` or `path.relative` to ensure path evaluation matches the final intended path. As a defense-in-depth measure, use a bounded regex like `/(^|\/)\.\.(?=\/|$)/` to explicitly detect and reject traversal attempts.
