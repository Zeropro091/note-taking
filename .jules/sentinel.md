## 2024-05-24 - Path Traversal Bypass via Backslash Sequences
**Vulnerability:** The note ID validation (`validateNoteId`) failed to normalize backslashes before running `path.resolve()`, which allowed POSIX traversal bypasses (e.g., `folder/..\\..\\etc\\passwd`) since backslashes aren't treated as path separators strictly before `resolve()`, while `path.relative` might interpret paths differently, allowing dangerous traversals.
**Learning:** Normalizing input using path-agnostic replacement (e.g. `replace(/\\/g, '/')`) BEFORE passing user-provided IDs to any node `path` utility is crucial. `path.resolve` combined with `path.relative` is insufficient security on its own if backslashes allow evasion of traversal string-checking blocks.
**Prevention:** As a defense-in-depth measure, normalize all backslashes to forward slashes first, and explicitly block any instances of `..` string patterns immediately before performing the directory containment checks with `path.resolve`/`path.relative`.
