## 2024-05-27 - [Defense-in-Depth against Cross-Platform Path Traversal via Backslashes]
**Vulnerability:** While POSIX systems treat backslashes (`\`) as literal filename characters rather than path separators, failing to normalize backslashes before validation (using `path.resolve`) can allow maliciously crafted payloads (e.g., `folder\..\..\etc\passwd`) to bypass traversal filters. This creates strangely named files on Linux. If this application's data is later migrated, synced, or evaluated on a Windows environment, these files could trigger actual path traversals.
**Learning:** Security validation logic should account for cross-platform edge cases. Never rely solely on `path.resolve` for path traversal protection without considering how un-normalized path separators might behave if the data context changes (e.g., Linux to Windows migration).
**Prevention:** Always normalize all backslashes to forward slashes (`id.replace(/\\/g, '/')`) BEFORE calling `path.resolve` or performing path relative checks as a defense-in-depth measure.
