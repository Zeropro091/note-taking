## 2024-06-29 - Path Traversal bypass with POSIX normalization
**Vulnerability:** Path traversal check `validateNoteId` only checked relative paths with `path.relative` and missed checking for inner path traversals that use `..` if they ultimately resolve safely inside the root directory. Furthermore, malicious inputs could bypass path traversal checks on POSIX-based environments because backslashes `\` are valid characters but are typically used as directory separators in Windows paths.
**Learning:** `path.resolve` normalizes paths, allowing inner path traversal attempts `folder/../../` to succeed if they finally resolve within the target directory. Also, `path.resolve` handles backslashes inconsistently across POSIX and Windows. Normalizing backslashes to forward slashes before `path.resolve` prevents path-traversal bypasses on cross-platform setups.
**Prevention:** Always normalize backslashes to forward slashes (`id.replace(/\\/g, '/')`) before resolving file paths, and explicitly reject `..` traversal sequences using `id.includes('..')` as an early defense-in-depth measure, even if the final path theoretically resolves within bounds.
