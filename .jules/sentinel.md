## 2024-03-24 - [Fix Path Traversal POSIX Bypass]
**Vulnerability:** A path traversal vulnerability bypass was found in `validateNoteId`. Backslashes (`\`) were interpreted as normal characters rather than directory separators in POSIX environments, allowing payloads like `..\\..\\etc\\passwd` to bypass the `path.relative` check.
**Learning:** In Node.js, `path.resolve` and `path.relative` behave differently depending on the operating system. On POSIX systems (Linux/Mac), backslashes are valid file name characters, not path separators. An attacker could use backslashes to construct a payload that passes the validation check on a POSIX server but is later interpreted as a path separator by other parts of the application or underlying system. A defense-in-depth approach explicitly rejecting `..` is necessary.
**Prevention:** Normalize backslashes to forward slashes BEFORE resolving paths relative to the base directory. Additionally, explicitly reject any IDs containing `..` to prevent traversal attempts, even if they appear to resolve safely within the base directory.
