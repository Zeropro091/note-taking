## 2025-07-06 - POSIX Backslash Bypass for Path Traversal
**Vulnerability:** A path traversal vulnerability existed in `validateNoteId` where `path.resolve` combined with `path.relative` checks failed to block directory traversal on POSIX systems if the input used backslashes (e.g., `foo\..\..\etc\passwd`). Node.js `path` functions on POSIX do not interpret backslashes as path separators, so `path.resolve` treated `foo\..\..\etc\passwd` as a valid filename, passing the `!relative.startsWith('..')` check.
**Learning:** Security validations relying on path manipulation APIs (like `path.resolve` and `path.relative`) are highly dependent on the underlying OS. Validations that are safe on Windows might easily be bypassed on POSIX if cross-platform path separators (backslashes) are not normalized first.
**Prevention:** Always normalize path separators (e.g., `replace(/\\/g, '/')`) BEFORE performing path traversal checks or resolving paths. Additionally, explicitly reject `..` segments bounded by path separators using regex as a defense-in-depth measure, rather than relying solely on `path.relative` or broad `.includes('..')` checks.
